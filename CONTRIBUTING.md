# Contributing

Edit in make-tanakh-review (no git needed): sign in with GitHub, edit clause by clause, save. Each save is a commit under your
own name on your own branch (in your fork, unless you have write access here) and opens one pull request; a reviewer merges it
into `main` verse by verse; the language team approves chapters into `approved`.

You can also edit with git or on github.com: any pull request into `main` that changes chapter files is a proposal and shows
up in the review page the same way.

By saving or opening a pull request you give your edit under CC0 1.0 (public domain dedication), as all text here. Your first
pull request records that agreement in its description.

Reviewers are self-serve: ask in the editor (or open an issue "reviewer request") and you are added to `roles.json`. The
language team is set by its members in `roles.json` and `CODEOWNERS`.
